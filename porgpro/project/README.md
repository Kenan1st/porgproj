## das Programm bekommen sie folgender maßen zum Laufen:

- java -jar lvp-0.5.4.jar --log --watch=FuncGraphMd.java in die Befehlszeile eingeben
- Sie müssen keine Weiterern eingaben zum "zum laufen Bringen" tätigen
- es wird automatisch die funktion: e^(sin(x)) angewandt
- in dem Feld exampleValue können sie ihren eigen ausdruck eingeben (infix- oder UPN)
- bei dem skalierer können sie den sichtbereich der Graphik einstellen (mit scaleX und sacleY)
- unter dem Baum wird der Ausdruck in der jeweils anderen Notation angezeigt
- über dem Eingabefeld von exampleValue sthet der momentan verwendete Ausdruck
